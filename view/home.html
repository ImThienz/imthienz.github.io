Open Utilities

Github

Github is a platform for developers to host repositories, manage projects, collaborate with others, and share source code using Git.

Cydia

Cydia is a third-party app store for jailbroken iOS devices, giving users access to apps and system tweaks beyond Apple's restrictions.

TrollStore

TrollStore is a utility that exploits the CoreTrust bug to permanently install and sign IPA apps with powerful entitlements, without jailbreak.

AltStore

AltStore is a third-party app store for iOS devices, allowing users to install and manage apps without jailbreaking their devices.
AltStore Classic 2.3 is back!

SideStore

SideStore is an alternative app store for seamless sideloading. No jailbreak needed, and no computer after the initial install, only a WiFi connection.

Nugget

Unlock your device's full potential!
Customize your device with animated wallpapers, disable pesky daemons, and more!

StikDebug

StikDebug is an iOS debugging tool for viewing logs, managing processes, enabling JIT, and simulating GPS locations.

3105

3105 is an iOS customization utility for applying patches, editing system files, and installing various customization features.
